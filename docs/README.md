# Dərin sənədlər

Bu qovluqda layihənin ayrı-ayrı mövzuları üzrə təfərrüatlı sənədlər saxlanılır.
Ümumi baxış üçün kök qovluqdakı [../README.md](../README.md) faylına bax.

## Mövcud sənədlər

⏳ *Hələ yoxdur — layihə inkişaf etdikcə buraya əlavə olunacaq.*

## Gözlənilən mövzular

Layihə irəlilədikcə aşağıdakı sənədlər burada yaranacaq:

| Fayl | Mövzu |
|---|---|
| `fizika.md` | Lay fizikası: axın tənlikləri, faza davranışı |
| `riyaziyyat.md` | Diskretizasiya, xətti həll, konvergensiya |
| `grid.md` | Şəbəkə (grid) strukturu və həndəsə |
| `quyular.md` | Quyu modeli və iş rejimləri |
| `fayl_formatlari.md` | Giriş/çıxış fayllarının sxemi |
| `testler.md` | Test strategiyası və doğrulama |

> Yeni sənəd əlavə edəndə bu cədvəli yeniləməyi unutma.
